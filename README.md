# BuiltSELL — Free AI Projects, Prompts & Coding Platform

**BuiltSELL** is a 100% free community platform for discovering, uploading, commanding, and downloading **AI Projects**, **AI Prompts**, and **Coding Kits**.

## Features
- **Explore Free Assets (`/`):** Browse AI Projects, AI Prompts, and Coding Templates with live code/prompt previews and one-click copy.
- **Upload Projects:** Upload full `.zip` project archives or source/prompt files up to 50 MB.
- **Command & Download Hub (`/command`):** Configure runtime bundles, copy quick CLI pull commands, and download project archives for free.
- **Private Admin Portal (`/admin`):** Hidden administration route restricted to the first registered founder account (`#1`).

## Quick Start
```bash
npm install
npm run dev
```
